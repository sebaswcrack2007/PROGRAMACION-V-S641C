# 🎓 StudentFlow · Sistema de Gestión Académica

**StudentFlow** es una aplicación web full-stack diseñada para la administración y control de la vida académica estudiantil. Permite gestionar de forma eficiente materias, tareas y recordatorios personalizados a través de una interfaz moderna y una API REST robusta.

Este repositorio está estructurado como un **Monorepo**, dividiendo claramente la lógica del servidor (Backend) y la interfaz de usuario (Frontend) en directorios independientes.
